# Input
- [ ] Default control scheme doesn't adapt to O3DS
    > N3DS control scheme have all buttons sensibly mapped and let the player move and control freely.
    > O3DS control scheme doesn't have all buttons mapped; most notably it's impossible to look around, shoot or open the automap
    > It should be possible to create an ad-hoc control scheme for O3DS by running `APT_CheckNew3DS()`
